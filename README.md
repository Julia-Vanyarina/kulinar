# Кулинарная тетрадь

Личное приложение для iPhone: рецепты, находки из магазинов, кулинарные заметки, меню на неделю и список покупок.

Код лежит на GitHub (GitHub Pages). **Все рецепты, фото и меню хранятся только в телефоне** и в GitHub не попадают.

## Что умеет

- **Рецепты**: название, категория, время, выход, фото, ингредиенты по этапам, инвентарь, технология, заметки, источник.
  - Пересчёт на другое количество порций или креманок (например, 10 → 14 шт).
  - Кнопка «Всего продуктов» складывает одинаковые продукты из всех этапов.
  - Избранное (★), поиск, фильтр по категориям.
- **Находки**: вкусные продукты из магазинов с фото, магазином, ценой, оценкой сердечками и комментарием.
- **Рестораны и доставки** (вкладка «Находки» → переключатель): адреса с кнопкой «открыть в Яндекс Картах», телефон, сайт, что заказывать, уровень цен, оценка и фото.
- **Заметки**: цветные листочки с фото, можно закрепить сверху.
- **Меню**: блюда на 7 дней (завтрак, обед, ужин, перекус, десерт), сначала избранные рецепты. Из меню собирается общий **список покупок** с учётом порций.
- **Праздники** (вкладка «Меню» → «Праздники»): дата, гости, меню по разделам (закуски, салаты, горячее, десерты…) из своих рецептов или просто названием. Четыре рамки на выбор: «Аура», «Лаванда», «Тоскана», «Лимонная роща». Готовую **картинку с меню** можно отправить друзьям или сохранить в Фото. Есть список покупок, пересчитанный на число гостей.
- Всё можно редактировать и удалять.
- **Ещё**: номер версии, проверка и установка обновлений, сохранение и восстановление резервной копии.

## Мышка-помощница

Мышка в поварском колпаке (по умолчанию её зовут Крошка) живёт вверху экранов. Она подсказывает по ситуации: напомнит про копию и обновление, про пустое меню на завтра и близкий праздник. Ещё она задаёт вопросы («сладкого или посытнее?») и предлагает рецепт. Нажми на неё, чтобы услышать новый кулинарный совет, а крестиком её можно спрятать. Во вкладке «Ещё» мышку можно выключить или переименовать.

## Как выложить на GitHub

1. На github.com создай новый репозиторий, например `kulinar` (Public).
2. Нажми **Add file → Upload files** и перетащи **всё содержимое** папки `kulinar` (файлы и папки `css`, `js`, `icons`). Нажми **Commit changes**.
3. Открой **Settings → Pages**. В «Branch» выбери `main` и папку `/ (root)`, нажми **Save**.
4. Через 1–2 минуты появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/kulinar/`.

## Как поставить на iPhone

Открой адрес в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**. Запускай приложение с иконки: так оно работает без интернета и хранит данные отдельно от Safari.

## Как выпустить обновление

1. Внеси изменения в файлы.
2. Поменяй номер версии **в двух местах**:
   - `js/version.js` — `self.APP_VERSION = '1.0.1';`
   - `version.json` — `"version": "1.0.1"` (и коротко опиши изменения в `"notes"`).
3. Загрузи изменённые файлы на GitHub.

В приложении на вкладке «Ещё» появится красная точка и кнопка **«Обновить до 1.0.1»**. Обновление меняет только само приложение, данные остаются в телефоне.

## Резервная копия

«Ещё» → **Сохранить копию**. Получится один файл `kulinar-backup-ГГГГ-ММ-ДД.json` со всеми рецептами, находками, заметками, меню и фото. Сохрани его в «Файлы» или на Яндекс Диск.

Чтобы вернуть данные (например, на новом телефоне): «Ещё» → **Восстановить из файла**.

Если копию давно не сохраняли, на экране рецептов появится напоминание.

## Ингредиенты

В рецепте ингредиенты вводятся строками: продукт, количество, единица. Кнопка «+ этап» добавляет заголовок этапа (например, «Крем»). Готовый список можно вставить целиком через «Вставить текстом». Приложение понимает «Мука 200 г», «Мука — 200 г» и «200 г муки», а маркеры `•` уберёт само.

Если указать порцию (например, 10 шт по 350 мл), в рецепте можно будет пересчитать граммы и на другое количество, и на другой объём креманок.

## Файлы

```
index.html            — страница приложения
manifest.webmanifest  — название и иконка для экрана «Домой»
sw.js                 — работа без интернета и обновления
version.json          — номер последней версии (по нему проверяются обновления)
css/style.css         — оформление
js/version.js         — номер версии приложения
js/db.js              — база данных в телефоне
js/photos.js          — сжатие и хранение фото
js/ingredients.js     — разбор и пересчёт ингредиентов
js/doodles.js         — рисунки и иконки
js/backup.js          — резервная копия
js/places.js          — рестораны и доставки
js/holidays.js        — праздники
js/menucard.js        — картинка с праздничным меню
js/mouse.js           — мышка-помощница: подсказки, советы, вопросы
js/starter.js         — рецепты, которые добавляются при обновлении
js/app.js             — экраны и логика
icons/                — иконки приложения
```

## История версий

- **1.6.0**: картинка меню на своём фото из галереи (с подложкой под текстом), семь шрифтов на выбор, формат «Пост 4:5» или «Сторис 9:16».
- **1.5.0**: ингредиенты вводятся строками (продукт / сколько / единица) или текстом без тире; порция в рецепте («10 шт по 350 мл») с пересчётом на другой объём; рамки меню «Аура», «Лаванда», «Тоскана», «Лимонная роща».
- **1.4.0**: дизайн «аура и звёздочки», мультяшная мышка, новые рамки праздничной картинки («Аура», «Закат», «Лаванда», «Лимонад»).
- **1.3.0**: добавлены рецепты: банановый трайфл с карамелью, идеальная лазанья, тирамису.
- **1.2.0**: новый акварельный дизайн, мышка-помощница с подсказками и вопросами (включается и переименовывается во вкладке «Ещё»), новые рамки для праздничной картинки.
- **1.1.0**: рестораны и доставки, праздники с картинкой-меню и списком покупок на гостей.
- **1.0.0**: первая версия.
